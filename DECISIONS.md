# Решения

## 2026-10-13 — Тайм-коды по id карточки
- **Fallback при чтении, а не миграция хешей.** Хеш считают разные места (ядро, плагины) по разным формулам,
  поэтому пересчитать старые хеши под новое название нельзя. Вместо этого при промахе по хешу ищем запись
  по `card|season|episode` в индексе, а прогресс дальше пишем под новым хешем.
- **Старую запись не удаляем.** Ее могут читать другие устройства и старые версии приложения.
- **Ключ включает тип и источник.** В TMDB id фильма и сериала пересекаются, у других источников свои id.
- **Привязка передается явно через `Timeline.link()`.** Угадывать карточку из активной activity ненадежно,
  а сезон/серию оттуда не получить. Сторонние плагины без `link` работают как раньше.
- **На сервере только расширили whitelist в `timeline/update`.** Схема БД не меняется: поля лежат в JSON-колонке `data`,
  а `dump/changelog` уже отдают ее целиком.
