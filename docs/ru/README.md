## Быстрый старт

```js
function startMyPlugin() {
    window.my_plugin_ready = true

    function init() {
        // Регистрация шаблонов, компонентов, настроек, пунктов меню…
    }

    if (window.appready) init()
    else Lampa.Listener.follow('app', e => { if (e.type == 'ready') init() })
}

if (!window.my_plugin_ready) startMyPlugin()
```

## Шпаргалка по глобальному пространству имён

| Объект | Назначение |
|---|---|
| `Lampa.Listener` | Глобальная шина событий приложения |
| `Lampa.Storage` | Персистентное хранилище ключ-значение |
| `Lampa.Lang` | Локализация — добавление и перевод строк |
| `Lampa.Template` | Регистрация и получение HTML-шаблонов |
| `Lampa.Activity` | Навигация — push/pop экранов |
| `Lampa.Component` | Регистрация компонентов по имени |
| `Lampa.Reguest` | Обёртка над HTTP (использовать через `new`) |
| `Lampa.Select` | UI выпадающего списка (bottom-sheet) |
| `Lampa.Modal` | UI модального окна |
| `Lampa.Noty` | Всплывающее уведомление |
| `Lampa.Player` | События жизненного цикла плеера |
| `Lampa.PlayerVideo` | События видеоэлемента |
| `Lampa.PlayerPanel` | Панель плеера (дорожки, субтитры) |
| `Lampa.SettingsApi` | Добавление секций и параметров настроек |
| `Lampa.Manifest` | Метаданные приложения + регистрация плагинов |
| `Lampa.Platform` | Определение платформы |
| `Lampa.Subscribe` | Создание приватной шины событий |
