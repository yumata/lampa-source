# Обзор и структура файлов

## Что такое плагин Lampa?

Плагины Lampa — это самостоятельные JavaScript-файлы, которые внедряются в работающее приложение через тег `<script>`. В момент запуска приложение экспортирует всё своё внутреннее устройство через `window.Lampa`, и плагин взаимодействует с ним исключительно через это пространство имён — никаких бандлеров, систем импортов и React.

**Плагины могут:**

- Добавлять новые экраны (Activity-компоненты), доступные из главного меню
- Добавлять пункты в контекстное меню карточек («Смотреть через…»)
- Регистрировать секции настроек с переключателями, выпадающими списками и текстовыми полями
- Реагировать на события плеера для изменения поведения воспроизведения
- Внедрять CSS и пользовательские HTML-шаблоны
- Читать и записывать пользовательские настройки через Storage
- Обращаться к внешним серверам через встроенную обёртку над HTTP

## Структура файлов

При сборке внутри исходного кода приложения каждый плагин располагается в отдельной директории под `plugins/`. Имя директории должно совпадать с именем входного файла.

```
plugins/
  my-plugin/
    my-plugin.js     ← точка входа Rollup (собирается как IIFE)
    css/
      style.css      ← внедряется через Template во время выполнения
    component.js     ← дополнительные модули плагина
    api.js
```

**Внешние плагины** (хранятся на удалённом сервере и устанавливаются пользователями) следуют той же схеме, но распространяются как единый скомпилированный файл. Приложение загружает и внедряет их при запуске.

> **Заметка о `@@include`:** Конструкция `@@include('../plugins/name/css/style.css')` — это **директива времени сборки**, которую обрабатывает `gulp-file-include`. Она встраивает содержимое CSS-файла в скомпилированный JS плагина. Во время выполнения строка `<style>` уже встроена — нужно просто добавить её в body через Template.

## Паттерн защиты от двойной загрузки

Плагины могут загружаться более одного раза — при переустановке или если пользователь добавил один и тот же URL дважды. Без защиты это приводит к дублированию пунктов меню, обработчиков событий и шаблонов.

**Всегда оборачивайте плагин в уникально именованную функцию и проверяйте глобальный флаг:**

```js
function startMyPlugin() {
    // Предотвращает повторное выполнение при перезагрузке / переустановке
    window.my_plugin_ready = true

    // … весь код плагина …
}

if (!window.my_plugin_ready) startMyPlugin()
```

Имя глобального флага должно быть уникальным среди всех плагинов. Используйте имя, производное от названия вашего плагина.

## Защита `appready`

Приложение заполняет `window.Lampa` до начала последовательности загрузки, но многие модули (Menu, Activity, Settings, Player) ещё не инициализированы. Обращение к ним до события `app:ready` вызывает ошибки с null-ссылками.

```js
function init() {
    // Здесь все API Lampa.* безопасны для использования
    registerTemplates()
    registerComponents()
    addMenuItem()
}

// Если плагин загружается после полного запуска, appready уже true
if (window.appready) init()
else Lampa.Listener.follow('app', function(e) {
    if (e.type == 'ready') init()
})
```

> **Правило:** Никогда не вызывайте `Lampa.Activity.push()`, не читайте `.menu__list` и не взаимодействуйте с Settings вне `init()`.

## Минимальный скелет плагина

```js
function startMyPlugin() {
    window.my_plugin_ready = true

    // ── Шаблоны ────────────────────────────────────────────────────
    Lampa.Template.add('my_main', `
        <div class="my-plugin">
            <div class="my-plugin__title">{title}</div>
        </div>
    `)

    // ── Локализация ────────────────────────────────────────────────
    Lampa.Lang.add({
        my_title: { ru: 'Мой плагин', en: 'My Plugin' }
    })

    // ── Компонент ──────────────────────────────────────────────────
    function MyComponent(object) {
        let html = Lampa.Template.get('my_main', { title: 'Привет' })

        this.create  = function() { return this.render() }
        this.start   = function() {}
        this.stop    = function() {}
        this.destroy = function() { html.remove() }
        this.render  = function() { return html }
    }

    // ── Регистрация и подключение ──────────────────────────────────
    function init() {
        Lampa.Component.add('my_plugin_screen', MyComponent)

        let btn = $('<li class="menu__item selector"><div class="menu__text">' +
                    Lampa.Lang.translate('my_title') + '</div></li>')

        btn.on('hover:enter', () => Lampa.Activity.push({
            url: '', title: Lampa.Lang.translate('my_title'),
            component: 'my_plugin_screen', page: 1
        }))

        $('.menu .menu__list').eq(0).append(btn)
    }

    if (window.appready) init()
    else Lampa.Listener.follow('app', e => { if (e.type == 'ready') init() })
}

if (!window.my_plugin_ready) startMyPlugin()
```

## Совместимость версий

```js
// Числовая версия для сравнений (например, 3.2.8 → 328)
if (Lampa.Manifest.app_digital >= 300) {
    // Безопасно использовать API v3.0+ (Maker, модульные карточки и т.д.)
}

// Строковая версия для отображения
console.log('Версия приложения:', Lampa.Manifest.app_version) // "3.2.8"
```
